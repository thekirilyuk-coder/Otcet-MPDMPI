# Отчёты МПД / МПИ

Дашборд «Итоги направлений» (сентябрь 2026): вкладки «Исполнение сделок» и «Подготовка договоров». Файлы открываются в браузере, без зависимостей.

- `compare.html` — **сравнение вариантов**: переключатель «Вариант 1 / 2 / 3» в правом нижнем углу (или клавиши `1`, `2`, `3`). Выбранная вкладка и прокрутка сохраняются при переключении.
- `variants/v1.html` — вариант 1 (зафиксирован, он же ветка `v1`).
- `variants/v2.html` — вариант 2 (зафиксирован, он же ветка `v2`): шестерёнка в шапке открывает панель «Настройка отчёта» — включение и отключение блоков (главная цифра, карточки, графики, таблица) и данных внутри них (серии графиков, колонки таблицы, отдельные карточки). Настройка запоминается в браузере, «Показать всё» возвращает исходный вид.
- `variants/v3.html` — вариант 3 (в работе): один лендинг без вкладок — оба направления на одной странице друг за другом. Один жёлтый блок в начале — сколько автомобилей передано за месяц; среднее время подготовки договора перенесено в карточки направления 2. Шестерёнка позволяет отключать целиком направление, а также блоки и данные внутри него.

## Как обновить сравнение

После правок в `variants/` пересоберите страницу сравнения:

```bash
python3 tools/build_compare.py
```

Новый вариант — просто добавьте `variants/v3.html` и пересоберите.
